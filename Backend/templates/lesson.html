APIs & Web Scraping

Learn how to fetch data from web services using APIs and web scraping techniques. Understand authentication, JSON, and practical examples with Python.

1 Introduction to APIs

APIs (Application Programming Interfaces) are how modern software communicates. They let your Python code talk to other services over the internet—from AI models to weather data to social media platforms.

An API is essentially a contract between your code and a remote server. When you make a request to an API, you're asking a service to do something or send you data. The server processes your request and sends back a response.

Why APIs Matter

  • Access real-time data from services worldwide
  • Integrate third-party functionality into your applications
  • Build systems that communicate across the internet
  • Work with structured, documented data sources

2 The Waiter Analogy

Think of an API like a waiter in a restaurant:
  • You (the customer) make a request
  • The waiter takes it to the kitchen (server)
  • The kitchen prepares your order (processes data)
  • The waiter brings back your food (returns data)

Just like you don't go into the kitchen yourself, you don't directly access a remote server's databases. Instead, you use the API—the waiter—to request what you need.

Request

You send a structured message asking for something. This is like placing an order.

Processing

The server receives your request and performs the necessary operations.

Response

The server sends back data or confirmation. This is your meal arriving at the table.

Standard APIs in Python

With standard APIs, we send a request and the server sends back raw data, usually in JSON format. We use Python's requests library to handle this communication:

import requests response = requests.get(url) data = response.json()

This simple pattern—import requests, make a request, parse the JSON—is used thousands of times across data science projects.

3 API Keys & Authentication

What is an API Key?

A long string of random characters that tells the server who you are. Think of it like a VIP wristband or credit card—it grants access and tracks your usage.

Authentication

Proves you're the legitimate user making requests. Prevents unauthorized access.

Usage Tracking

APIs track how much data you request using your key. This helps providers manage resources.

Billing

For paid APIs, your key links you to your account so you can be charged accurately.

The Golden Rule: NEVER share your API key. If someone steals it, they can use your quota and potentially your money. Treat it like a password.

Best Practice: Secure Your Keys

If you post code on GitHub, hide your keys first using environment variables.

# DON'T do this: api_key = "sk-1234567890abcdef" # visible in code! # DO this instead: import os api_key = os.getenv("API_KEY") # reads from environment

Store your API key in a .env file (add to .gitignore), and use the python-dotenv library to load it safely.

4 JSON: The Universal Language

Most APIs send data back in JSON (JavaScript Object Notation) format. The good news? JSON looks exactly like a Python dictionary!

{ "name": "Alice", "age": 30, "city": "New York" }

It's just keys and values, organized in a structure Python already understands.

Converting JSON to Python

When you receive data from an API, one simple command converts the web text into a Python dictionary:

data = response.json() print(data["name"]) # Alice print(data["age"]) # 30 print(data["city"]) # New York

Why JSON is Perfect for APIs

  • Human-readable format developers can understand
  • Maps perfectly to Python dictionaries and lists
  • Works across all programming languages
  • Supports nested structures for complex data

5 Web Scraping Basics

While APIs offer structured access to data, not all websites provide them. Web scraping is the art of programmatically extracting information directly from web pages, turning unstructured HTML into usable data.

Think of it as having a super-fast assistant who can read a website and copy-paste exactly the pieces of information you need, but on a massive scale. Python, with its powerful libraries like BeautifulSoup and Requests, makes this process efficient and manageable.

When to Use Web Scraping

No API Available

The website doesn't provide an API for accessing data.

Real-Time Data

You need current data that updates frequently on a website.

Large Datasets

Extracting information from tables or lists across multiple pages.

⚠️ Important Note: Always respect robots.txt and terms of service. Some websites explicitly prohibit scraping. Make sure you have permission before scraping a site.

6 Practical Code Examples

Example 1: Web Scraping in Action

This Python script uses the requests library to fetch a webpage and BeautifulSoup to parse the HTML, allowing us to extract specific pieces of information:

import requests from bs4 import BeautifulSoup # Define the URL of the page to scrape url = 'http://example.com' # Send an HTTP GET request to the URL response = requests.get(url) # Parse the HTML content of the page soup = BeautifulSoup(response.text, 'html.parser') # Find the <title> tag and extract its text page_title = soup.find('title').get_text() print(f"Extracted Page Title: {page_title}")

This simple script demonstrates the core steps of web scraping: fetching the HTML, parsing it, and navigating the structure to pull out desired content.

Example 2: Using a Client Library (Google Gemini)

Some APIs are complex (like AI services). Instead of dealing with raw HTTP requests, we use a wrapper library that simplifies everything.

# Install the Library # pip install google-generativeai import google.generativeai as genai # Configure with Your Key genai.configure(api_key="YOUR_KEY_HERE") # Ask Questions! model = genai.GenerativeModel('gemini-pro') response = model.generate_content("Tell me a joke") print(response.text)

Key Takeaways

  • APIs are like waiters—they bring data from servers to your code
  • Always protect your API keys like passwords
  • JSON is the universal data format—convert it to Python dictionaries
  • Web scraping lets you access data when APIs aren't available
  • BeautifulSoup makes parsing HTML simple and intuitive
  • Client libraries hide complexity—when available, use them
